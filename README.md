# Student Management System

Modern student management platform scaffold built with Next.js, React, Node.js, and Python.

## Structure

- `apps/web` - Next.js student and staff portal
- `apps/api` - Node.js API for auth, school workflows, and data orchestration
- `services/analytics` - Python service for reporting and automation

## Current status

The workspace currently contains the first implementation pass: a branded landing dashboard, a Node API with mock school data, and a Python analytics service skeleton.
